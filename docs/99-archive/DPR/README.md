# Delivery Progress Reports (DPR)

Milestone-progress records — each DPR records the implementation status and direction at a point in a
milestone. A DPR is factual and forward-pointing; it authorizes no work (a Sprint Assignment does that).
DPRs are **superseded**, never rewritten (`CLAUDE.md` §14.4, §16.2).

The series began as *Delta* Progress Reports (DPR-001…005) and continues across later milestones
(DPR-006… cover **Milestone Epsilon**); the numbering is continuous and is never reused.
