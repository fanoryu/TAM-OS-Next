# 05 — Milestones

The record of what has landed, grouped into named eras. Where the [Roadmap](../01-roadmap/README.md)
looks forward, milestones look at the track as a whole and mark completion.

| Document | Read it for |
|---|---|
| [Milestones.md](Milestones.md) | Each milestone (Alpha → Omega), its theme, and its status |

A milestone advances to **Completed** only when every pull request beneath it is merged, verified, and
reflected on `main`. This folder tracks status; it does not authorize work.
