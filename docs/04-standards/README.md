# 04 — Standards

How each kind of engineering work is performed. These standards document the workflow already
established and exercised during PR-5D through PR-5F; they codify existing practice rather than
inventing a new process.

| Document | Governs |
|---|---|
| [SPR_Standard.md](SPR_Standard.md) | Sprint Assignments — how work is authorized and scoped |
| [PR_Standard.md](PR_Standard.md) | Pull Requests — structure, scope, and pre-review gates |
| [Review_Standard.md](Review_Standard.md) | Review — what a reviewer must confirm |
| [Merge_Standard.md](Merge_Standard.md) | Merge — pre-merge and post-merge gates |
| [Coding_Standard.md](Coding_Standard.md) | Code — style, purity, and Domain rules |
| [Testing_Standard.md](Testing_Standard.md) | Verification — verifier, runtime checks, browser validation |
| [Release_Standard.md](Release_Standard.md) | Release — how a version is proposed and published |

These standards operationalize the [Engineering Constitution](../00-governance/Engineering_Constitution.md)
and defer to [`CLAUDE.md`](../../CLAUDE.md) for the enforceable rules and the Approval Matrix (§20).
Where a standard and `CLAUDE.md` could be read differently, `CLAUDE.md` governs.
